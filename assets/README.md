# assets/

- `brand.yml` — цвета и подпись фирменной карточки. Правьте под свой бренд.
- `generated/` — сюда пайплайн кладёт отрисованные карточки и скачанные стоковые фото.
  Папка в `.gitignore`: картинки не коммитятся, они пересоздаются.
- `fonts/` — сюда можно положить свой шрифт (`.ttf`). Если его нет,
  используется системный DejaVu Sans, который есть на ubuntu-раннерах GitHub.

Логотип: сейчас на карточке рисуется плейсхолдер — акцентный квадрат плюс
название из `brand.yml`. Чтобы поставить настоящий логотип, положите
`assets/logo.png` и допишите его отрисовку в `pipeline/illustrate.py::render_card`.
