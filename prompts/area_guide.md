## Входные данные

Единственный разрешённый источник цифр по району:

<INPUT_ITEMS>{{items}}</INPUT_ITEMS>

## Цель поста

Дать честный портрет одного района: кто там живёт, сколько стоит, что работает
и что не работает. Рубрика знакомит с географией города, готовя читателя
к лончам, и собирает контакты через PDF-гид.

**Главный признак качества — блок минусов.** Без него пост неотличим от
брошюры и не выполняет задачу доверия.

## Структура

1. **Заголовок** — район и его характер одним словом-крючком.
2. **«Кто живёт»** — 1–2 предложения про типичного жителя района.
3. **Цифры** — 3–4 буллета из источника: средняя цена сделки, аренда по типу
   жилья, число сделок за период, диапазон service charge. С периодом и источником.
4. **«Что работает»** — 2–3 пункта: инфраструктура, соотношение цены и площади,
   транспорт.
5. **«Что не работает»** — 2–3 пункта. Обязательный блок: стройка, транспорт,
   качество управляющих компаний, шум, отсутствие метро.
6. **«Кому подходит / кому нет»** — две короткие строки.
7. **CTA** — на PDF-гид по району.
8. **Хештеги** — включая название района.

## Длина

Целевая: 500–600 символов. Потолок: `{{max_chars}}`.

## CTA

Средней жёсткости, на лид-магнит:

- «Подробный PDF-гид по району — заберите в боте, там цифры по конкретным башням.»
- «Какой район разбираем следующим — напишите в комментариях.»

## Изображение

- `image.mode`: `"stock"` — общий вид застройки района. **Не использовать
  рендеры застройщиков как фото района.** Если есть проверенное фото
  из источника — можно `"press"`.
- `image.headline`: название района и характеристика, до 60 символов.
- `image.accent`: средняя цена или доходность по району, до 18 символов, только
  если цифра есть в `facts`. Иначе `""`.
- `image.stock_query`: на английском, с названием района из источника.

## Критичные self_check

- `all_numbers_have_source` — критичен. Цены и аренда по району — частое место
  выдумки.
- `no_guaranteed_returns` — критичен. Запрещено «район вырастет», «недооценён»,
  «перспективный». Только «по данным за {период} значение изменилось на {X}».
- `fits_telegram_limit`.

## Чего не делать

- Не писать пост без блока минусов — это провал рубрики.
- Не давать «среднюю цену по району» без указания типа жилья и периода.
- Не пересказывать инфраструктурные планы как свершившийся факт
  («скоро откроют метро») — только со ссылкой и датой.
- Не использовать слова «элитный», «премиальный», «лакшери», «локация».
- Максимум один эмодзи, можно и без него.

## Формат ответа — строго валидный JSON

Верни ТОЛЬКО JSON-объект по схеме ниже. Без markdown-обёртки, без тройных
кавычек, без комментариев, без текста до или после. Первый символ ответа — `{`,
последний — `}`.

```json
{
  "rubric": "<rubric_id>",
  "title": "строка, не длиннее 90 символов, без markdown",
  "body": "строка, текст поста; разрешены только теги <b>, <i>, <a href=\"...\"> (Telegram HTML)",
  "hashtags": ["#дубай", "#недвижимость"],
  "cta": "строка, одна фраза призыва к действию",
  "image": {
    "mode": "card",
    "headline": "строка не длиннее 60 символов для фирменной карточки",
    "accent": "строка не длиннее 18 символов: цифра-акцент, либо пустая строка",
    "stock_query": "english keywords for Unsplash/Pexels fallback"
  },
  "sources": [{"source_id": "...", "title": "...", "url": "https://..."}],
  "facts": [
    {
      "claim": "...",
      "value": "...",
      "source_url": "https://...",
      "confidence": "confirmed | single_source | rumour",
      "sources": ["https://...", "https://..."]
    }
  ],
  "self_check": {
    "all_numbers_have_source": true,
    "no_guaranteed_returns": true,
    "language_is_russian": true,
    "no_verbatim_copy": true,
    "fits_telegram_limit": true
  },
  "length_chars": 0,
  "needs_separate_text": false
}
```

Обязательные условия по полям:
- `rubric` — ровно то значение, что пришло в `RUBRIC_ID` выше (`{{rubric}}`).
- `title` — до 90 символов, без markdown и без эмодзи.
- `body` — только теги `<b>`, `<i>`, `<a href="...">`; переносы строк как `\n`.
- `hashtags` — 2–4 штуки, строчными, по-русски, первым `#дубай`.
- `cta` — одна фраза; она же дублируется в конце `body`.
- `image.mode` — `"card"`, `"stock"` или `"press"` согласно разделу «Изображение».
- `image.headline` — до 60 символов; `image.accent` — до 18 символов или `""`.
- `image.stock_query` — на английском, 3–6 слов, заполняется всегда.
- `sources[].source_id` — идентификатор источника **ровно так, как он пришёл
  в поле `source_id` соответствующего элемента `<INPUT_ITEMS>`** (например
  `gulf_news_rss`, `dld_open_data_portal`). Не подставляй сюда название
  категории и не придумывай новых идентификаторов.
- `sources[].url` — только из `<INPUT_ITEMS>`; конструировать ссылки запрещено.
- `facts` — по одной записи на каждую цифру, встречающуюся в `body`;
  `confidence` — `confirmed`, `single_source` или `rumour` по правилам раздела
  «Проверка и маркировка» системного промпта; `sources` — все url из
  `<INPUT_ITEMS>`, где этот факт встречается (первый дублируется в `source_url`).
- `self_check` — честная самопроверка; `false` лучше, чем ложный `true`.
- `length_chars` — фактическая длина `body` в символах.
- `needs_separate_text` — `true`, если полный текст не помещается в
  `{{max_chars}}` и нужна вторая часть отдельным сообщением.
