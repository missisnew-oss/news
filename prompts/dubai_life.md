## Цель поста

Дать читателю — жителю Дубая/ОАЭ или тому, кто сюда собирается, — одну
вещь о жизни в городе, которая **действительно** его касается. Это главная
рубрика канала, она держит ежедневную привычку читать, поэтому планка
здесь выше всего: каждый пост проходит тест «Кому это важно» из системного
промпта.

Подходит, если есть во входных данных:
- **городская новость с последствиями**: транспорт, дороги, метро, парковки,
  сезон и погода, если она меняет планы; открытия крупных объектов — парков,
  пляжей, торговых центров, набережных, музеев;
- **архитектура и стройка**: новые башни, мастер-планы районов, острова,
  мосты, крупные объекты и их сроки;
- **инфраструктура и сервисы для жителей**: DEWA, Salik, Ejari, RTA, банки,
  связь, школы, медицина, доставка — новости, тарифы, лайфхаки;
- **цифры о городе**, которые влияют на решение жить здесь: население,
  аренда, стоимость жизни, туристы, рейтинги, рекорды;
- **крупные события уровня города**, о которых будут говорить все;
- **бытовая процедура по шагам**, если материал именно об этом.

Не подходит: сделки и инвестиции (это другие рубрики), политика, происшествия
с пострадавшими, слухи без источника, и **филлер** — конкурсы, гороскопы,
фестиваль для обладателей вьющихся волос, «10 лучших кафе», сплетни,
мелкие акции. Если из трёх новостей недели две значимые, а третья филлер —
пост из двух новостей; филлер не добавляется «для полноты».

Это **непродающая** рубрика. CTA мягкий или отсутствует.

## Структура

Два формата — выбери по материалу.

**А. Новость (по умолчанию):**
1. **Заголовок** — что произошло, простой фразой.
2. **Суть** — 1–2 предложения: что это и кого касается.
3. **Факты** — 2–4 коротких строки или список через тире: где, когда, сколько.
4. **Что это значит для вас** — 1–2 строки: что делать, чего ждать, стоит ли
   идти/ехать. Своё мнение коротко.
5. **Хештеги.**

**Б. Инструкция (если материал — про процедуру):**
1. **Заголовок** — задача, а не тема. «Ejari за один вечер».
2. **Что понадобится** — короткий список.
3. **Как сделать** — 3–5 шагов.
4. **На чём спотыкаются** — 1–2 пункта.
5. **Хештеги.**

## Длина

Целевая: 280–440 символов. Потолок: `{{max_chars}}`.
Рубрика должна читаться быстро — короче здесь лучше, чем полнее.

## CTA

Мягкий, без воронки:

- «Сохраните — пригодится при переезде.»
- «Если у вас было иначе — напишите в комментариях, дополню.»

Жёсткие CTA на заявку в этой рубрике **запрещены**.

## Изображение

- `image.mode`: `"stock"`
- `image.headline`: задача, до 60 символов, без эмодзи.
- `image.accent`: обычно `""`. Цифру ставить только если она есть в `facts`,
  например срок оформления.
- `image.stock_query`: по теме на английском, например
  `"dubai apartment keys paperwork moving in"`.

## Критичные self_check

- `all_numbers_have_source` — критичен для пошлин, сроков, тарифов. Процедуры
  и суммы меняются; «по памяти» писать нельзя.
- `language_is_russian` — следи за транслитерациями: «Эджари», «Дэва»
  недопустимы. Пиши Ejari, DEWA латиницей с переводом при первом употреблении.
- `fits_telegram_limit`.

## Чего не делать

- Не писать процедуру без сверки с источником — правила меняются каждый год.
- Не называть суммы пошлин и тарифов без источника.
- Не превращать пост в продающий: никаких «а если решите купить — пишите».
- Не рекламировать конкретные заведения и сервисы без пометки, что это личный опыт.
- Эмодзи: максимум два, смысловые.

## Формат ответа — строго валидный JSON

Верни ТОЛЬКО JSON-объект по схеме ниже. Без markdown-обёртки, без тройных
кавычек, без комментариев, без текста до или после. Первый символ ответа — `{`,
последний — `}`.

```json
{
  "rubric": "<rubric_id>",
  "title": "строка, не длиннее 90 символов, без markdown",
  "body": "строка, текст поста; разрешены только теги <b>, <i>, <a href=\"...\"> (Telegram HTML)",
  "hashtags": ["#дубай", "#недвижимость"],
  "cta": "строка, одна фраза призыва к действию",
  "image": {
    "mode": "card",
    "headline": "строка не длиннее 60 символов для фирменной карточки",
    "accent": "строка не длиннее 18 символов: цифра-акцент, либо пустая строка",
    "stock_query": "english keywords for Unsplash/Pexels fallback"
  },
  "sources": [{"source_id": "...", "title": "...", "url": "https://..."}],
  "facts": [
    {
      "claim": "...",
      "value": "...",
      "source_url": "https://...",
      "confidence": "confirmed | single_source | rumour",
      "sources": ["https://...", "https://..."]
    }
  ],
  "self_check": {
    "all_numbers_have_source": true,
    "no_guaranteed_returns": true,
    "language_is_russian": true,
    "no_verbatim_copy": true,
    "fits_telegram_limit": true
  },
  "length_chars": 0,
  "needs_separate_text": false
}
```

Обязательные условия по полям:
- `rubric` — ровно то значение, что пришло в `RUBRIC_ID` выше (`{{rubric}}`).
- `title` — до 90 символов, без markdown и без эмодзи.
- `body` — только теги `<b>`, `<i>`, `<a href="...">`; переносы строк как `\n`.
- `hashtags` — 2–4 штуки, строчными, по-русски, первым `#дубай`.
- `cta` — одна фраза; она же дублируется в конце `body`.
- `image.mode` — `"card"`, `"stock"` или `"press"` согласно разделу «Изображение».
- `image.headline` — до 60 символов; `image.accent` — до 18 символов или `""`.
- `image.stock_query` — на английском, 3–6 слов, заполняется всегда.
- `sources[].source_id` — идентификатор источника **ровно так, как он пришёл
  в поле `source_id` соответствующего элемента `<INPUT_ITEMS>`** (например
  `gulf_news_rss`, `dld_open_data_portal`). Не подставляй сюда название
  категории и не придумывай новых идентификаторов.
- `sources[].url` — только из `<INPUT_ITEMS>`; конструировать ссылки запрещено.
- `facts` — по одной записи на каждую цифру, встречающуюся в `body`;
  `confidence` — `confirmed`, `single_source` или `rumour` по правилам раздела
  «Проверка и маркировка» системного промпта; `sources` — все url из
  `<INPUT_ITEMS>`, где этот факт встречается (первый дублируется в `source_url`).
- `self_check` — честная самопроверка; `false` лучше, чем ложный `true`.
- `length_chars` — фактическая длина `body` в символах.
- `needs_separate_text` — `true`, если полный текст не помещается в
  `{{max_chars}}` и нужна вторая часть отдельным сообщением.
