# Рубрика: events_afisha — «Афиша»

RUBRIC_ID: {{rubric}}
TODAY: {{today}}
MAX_CHARS: {{max_chars}}

## Входные данные

Единственный разрешённый источник событий, дат, мест и цен:

<INPUT_ITEMS>{{items}}</INPUT_ITEMS>

Каждое событие берётся только отсюда: название, дата, место, цена входа.
Событие без подтверждённой даты в пост не попадает. Событие, дата которого
раньше `{{today}}`, в пост не попадает.

## Цель поста

Дать читателю готовый план на выходные или ближайшую неделю. Самая лёгкая
рубрика канала: держит дневной охват и даёт пересылки — лучший предиктор роста
числа подписчиков.

Это **непродающая** рубрика.

## Структура

1. **Заголовок** — «Афиша выходных в Дубае» либо с крючком, если в источнике
   есть крупное событие.
2. **3–5 событий.** На каждое — 2–3 строки:
   - название жирным (`<b>`);
   - дата, время, место;
   - для кого и вход (платно или бесплатно) — если это есть в источнике.
3. **Одна-две строки личного комментария** — куда идти с детьми, где не будет
   парковки, когда приезжать. Это то, что отличает афишу от копипасты.
4. **CTA** — на сохранение или пересылку.
5. **Ссылки на источники.**
6. **Хештеги.**

## Длина

Целевая: 500–850 символов. Потолок: `{{max_chars}}`.
Если событий во входных данных больше пяти — выбери пять самых релевантных
русскоязычной аудитории (семейные, спорт, музыка, выставки), остальные отбрось.

## CTA

Мягкий:

- «Сохраните, чтобы в пятницу не искать заново.»
- «Перешлите тому, кто вечно спрашивает, чем заняться на выходных.»

Жёсткие CTA и упоминания недвижимости в этой рубрике **запрещены**.

## Изображение

- `image.mode`: `"stock"`. Если во входных данных есть официальный постер
  события — `"press"`.
- `image.headline`: «Афиша: {даты}» либо название главного события,
  до 60 символов.
- `image.accent`: обычно `""`. Можно число событий, если оно не требует источника.
- `image.stock_query`: `"dubai weekend event crowd evening lights"` либо по теме
  главного события.

## Критичные self_check

- `all_numbers_have_source` — цены билетов и даты только из входных данных.
  Неверная дата означает, что подписчики приехали зря, и это потеря доверия.
- `no_verbatim_copy` — описания событий переписывай своими словами.
- `fits_telegram_limit`.

## Чего не делать

- Не включать события, дата которых не указана или уже прошла относительно
  `{{today}}`.
- Не давать список из 10 событий без комментария — это лента, а не афиша.
- Не выдумывать цены билетов и возрастные ограничения.
- Не вставлять рекламу объектов.
- Эмодзи: максимум три.

## Формат ответа — строго валидный JSON

Верни ТОЛЬКО JSON-объект по схеме ниже. Без markdown-обёртки, без тройных
кавычек, без комментариев, без текста до или после. Первый символ ответа — `{`,
последний — `}`.

```json
{
  "rubric": "<rubric_id>",
  "title": "строка, не длиннее 90 символов, без markdown",
  "body": "строка, текст поста; разрешены только теги <b>, <i>, <a href=\"...\"> (Telegram HTML)",
  "hashtags": ["#дубай", "#недвижимость"],
  "cta": "строка, одна фраза призыва к действию",
  "image": {
    "mode": "card",
    "headline": "строка не длиннее 60 символов для фирменной карточки",
    "accent": "строка не длиннее 18 символов: цифра-акцент, либо пустая строка",
    "stock_query": "english keywords for Unsplash/Pexels fallback"
  },
  "sources": [{"source_id": "...", "title": "...", "url": "https://..."}],
  "facts": [{"claim": "...", "value": "...", "source_url": "https://..."}],
  "self_check": {
    "all_numbers_have_source": true,
    "no_guaranteed_returns": true,
    "language_is_russian": true,
    "no_verbatim_copy": true,
    "fits_telegram_limit": true
  },
  "length_chars": 0,
  "needs_separate_text": false
}
```

Обязательные условия по полям:
- `rubric` — ровно то значение, что пришло в `RUBRIC_ID` выше (`{{rubric}}`).
- `title` — до 90 символов, без markdown и без эмодзи.
- `body` — только теги `<b>`, `<i>`, `<a href="...">`; переносы строк как `\n`.
- `hashtags` — 2–4 штуки, строчными, по-русски, первым `#дубай`.
- `cta` — одна фраза; она же дублируется в конце `body`.
- `image.mode` — `"card"`, `"stock"` или `"press"` согласно разделу «Изображение».
- `image.headline` — до 60 символов; `image.accent` — до 18 символов или `""`.
- `image.stock_query` — на английском, 3–6 слов, заполняется всегда.
- `sources[].source_id` — идентификатор источника **ровно так, как он пришёл
  в поле `source_id` соответствующего элемента `<INPUT_ITEMS>`** (например
  `gulf_news_rss`, `dld_open_data_portal`). Не подставляй сюда название
  категории и не придумывай новых идентификаторов.
- `sources[].url` — только из `<INPUT_ITEMS>`; конструировать ссылки запрещено.
- `facts` — по одной записи на каждую цифру, встречающуюся в `body`.
- `self_check` — честная самопроверка; `false` лучше, чем ложный `true`.
- `length_chars` — фактическая длина `body` в символах.
- `needs_separate_text` — `true`, если полный текст не помещается в
  `{{max_chars}}` и нужна вторая часть отдельным сообщением.
