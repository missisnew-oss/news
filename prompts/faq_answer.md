# Рубрика: faq_answer — «Вопрос — ответ»

RUBRIC_ID: {{rubric}}
TODAY: {{today}}
MAX_CHARS: {{max_chars}}

## Входные данные

Вопрос подписчика (обезличенный) и фактура для ответа:

<INPUT_ITEMS>{{items}}</INPUT_ITEMS>

Если фактуры для конкретного утверждения нет — отвечай на уровне механики
процесса и явно пиши, что цифры надо сверить у первоисточника. Цифру, которой
нет во входных данных, не называй вовсе.

## Цель поста

Дать короткий прямой ответ на реальный вопрос читателя и показать, что здесь
отвечают по существу. Вторая задача — пригласить задать свой вопрос: это
основная точка входа в бот из непродающего контента.

## Структура

1. **Заголовок** — сам вопрос, сокращённый до сути, до 90 символов.
2. **Цитата вопроса** — в кавычках, одной строкой, обезличенно. Формулировку
   можно причесать, смысл менять нельзя.
3. **«Коротко: да / нет / зависит от…»** — прямой ответ **в первых двух
   строках**. Это обязательное требование рубрики: ответ не прячется в конце.
4. **«Как это устроено»** — 3–5 буллетов с механикой.
5. **«На что смотреть»** — 1–2 предложения про самое рискованное место.
6. **CTA** — на вопрос в бот.
7. **Хештеги.**

## Длина

Целевая: 280–440 символов. Потолок: `{{max_chars}}`.
Рубрика ценится за краткость. Если ответ не умещается — сузь вопрос, а не
растягивай пост.

## CTA

Средней жёсткости, на вход в бот:

- «Есть свой вопрос — присылайте в бот, разберу в следующем выпуске.»
- «Задайте вопрос по вашей ситуации — отвечу здесь, обезличенно.»

## Изображение

- `image.mode`: `"card"`
- `image.headline`: **сам вопрос**, до 60 символов, со знаком вопроса, без эмодзи.
- `image.accent`: короткий ответ — «Да», «Нет», «Зависит» — до 18 символов.
  Это единственная рубрика, где `accent` не обязан быть цифрой.
- `image.stock_query`: `"question mark speech bubble minimal desk"` либо по теме.

## Критичные self_check

- `all_numbers_have_source` — критичен. Соблазн назвать «примерно 20%» при
  ответе очень высок. Нет цифры в источнике — не называй её вовсе.
- `no_guaranteed_returns` — критичен для вопросов про доходность и одобрение
  виз или ипотек.
- `language_is_russian`.
- `fits_telegram_limit`.

## Чего не делать

- Не отвечать «всё индивидуально, пишите в личку» — это потеря рубрики.
- Не раскрывать детали, по которым автора вопроса можно узнать: профессия
  плюс сумма плюс район плюс срок.
- Не придумывать вопрос, если его нет во входных данных.
- Не прятать ответ после трёх абзацев вступления.
- Максимум один эмодзи, можно без него.

## Формат ответа — строго валидный JSON

Верни ТОЛЬКО JSON-объект по схеме ниже. Без markdown-обёртки, без тройных
кавычек, без комментариев, без текста до или после. Первый символ ответа — `{`,
последний — `}`.

```json
{
  "rubric": "<rubric_id>",
  "title": "строка, не длиннее 90 символов, без markdown",
  "body": "строка, текст поста; разрешены только теги <b>, <i>, <a href=\"...\"> (Telegram HTML)",
  "hashtags": ["#дубай", "#недвижимость"],
  "cta": "строка, одна фраза призыва к действию",
  "image": {
    "mode": "card",
    "headline": "строка не длиннее 60 символов для фирменной карточки",
    "accent": "строка не длиннее 18 символов: цифра-акцент, либо пустая строка",
    "stock_query": "english keywords for Unsplash/Pexels fallback"
  },
  "sources": [{"source_id": "...", "title": "...", "url": "https://..."}],
  "facts": [
    {
      "claim": "...",
      "value": "...",
      "source_url": "https://...",
      "confidence": "confirmed | single_source | rumour",
      "sources": ["https://...", "https://..."]
    }
  ],
  "self_check": {
    "all_numbers_have_source": true,
    "no_guaranteed_returns": true,
    "language_is_russian": true,
    "no_verbatim_copy": true,
    "fits_telegram_limit": true
  },
  "length_chars": 0,
  "needs_separate_text": false
}
```

Обязательные условия по полям:
- `rubric` — ровно то значение, что пришло в `RUBRIC_ID` выше (`{{rubric}}`).
- `title` — до 90 символов, без markdown и без эмодзи.
- `body` — только теги `<b>`, `<i>`, `<a href="...">`; переносы строк как `\n`.
- `hashtags` — 2–4 штуки, строчными, по-русски, первым `#дубай`.
- `cta` — одна фраза; она же дублируется в конце `body`.
- `image.mode` — `"card"`, `"stock"` или `"press"` согласно разделу «Изображение».
- `image.headline` — до 60 символов; `image.accent` — до 18 символов или `""`.
- `image.stock_query` — на английском, 3–6 слов, заполняется всегда.
- `sources[].source_id` — идентификатор источника **ровно так, как он пришёл
  в поле `source_id` соответствующего элемента `<INPUT_ITEMS>`** (например
  `gulf_news_rss`, `dld_open_data_portal`). Не подставляй сюда название
  категории и не придумывай новых идентификаторов.
- `sources[].url` — только из `<INPUT_ITEMS>`; конструировать ссылки запрещено.
- `facts` — по одной записи на каждую цифру, встречающуюся в `body`;
  `confidence` — `confirmed`, `single_source` или `rumour` по правилам раздела
  «Проверка и маркировка» системного промпта; `sources` — все url из
  `<INPUT_ITEMS>`, где этот факт встречается (первый дублируется в `source_url`).
- `self_check` — честная самопроверка; `false` лучше, чем ложный `true`.
- `length_chars` — фактическая длина `body` в символах.
- `needs_separate_text` — `true`, если полный текст не помещается в
  `{{max_chars}}` и нужна вторая часть отдельным сообщением.
