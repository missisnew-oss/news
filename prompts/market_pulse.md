# Рубрика: market_pulse — «Пульс рынка»

RUBRIC_ID: {{rubric}}
TODAY: {{today}}
MAX_CHARS: {{max_chars}}

## Входные данные

Единственный разрешённый источник фактов и цифр для этого поста:

<INPUT_ITEMS>{{items}}</INPUT_ITEMS>

Цифр, которых нет внутри `<INPUT_ITEMS>`, в посте быть не может.

## Цель поста

Дать читателю 3–5 проверяемых цифр за период и **одну интерпретацию**: что это
значит для человека, который покупает или собирается покупать. Пост не про
рынок «вообще» — он про решение читателя.

Бизнес-цели: ежедневный контакт с каналом плюс экспертность владельца.

## Структура

1. **Заголовок** — конкретный вывод периода, не «Пульс рынка».
   Пример формы: «Доля off-plan за неделю снова выросла».
2. **Одна строка контекста:** какой период и по каким данным.
3. **Список из 3–5 цифр** буллетами «•». Каждая — из входных данных, с подписью,
   что именно измерено. Формат: `• Что измерено — значение`.
4. **Блок «Что это значит»** — 2–4 предложения. Практический вывод для покупателя.
   Это ядро поста. Без него пост — пересказ новости.
5. **Оговорка при необходимости:** если данные за короткий период — прямо
   написать, что по неделе тренд не строится.
6. **CTA** — мягкий, вовлекающий.
7. **Хештеги.**

## Длина

Целевая: 700–950 символов. Жёсткий потолок: `{{max_chars}}`.
Если данных много — выбери 5 самых значимых и отбрось остальные, не сокращай
блок «Что это значит».

## CTA

Мягкий, без продажи. Варианты:

- «Какой район разобрать в следующий раз — напишите в комментариях»
- «Нужен срез по вашему району — задайте вопрос в боте»

Не используй «оставьте заявку» — это не продающая рубрика.

## Изображение

- `image.mode`: `"card"`
- `image.headline`: суть периода, до 60 символов, без эмодзи.
- `image.accent`: **главная цифра периода**, до 18 символов. Эта цифра
  обязана присутствовать в `facts`. Если ни одной уверенной цифры нет — `""`.
- `image.stock_query`: `"dubai downtown skyline aerial daytime"` или ближе к теме.

## Критичные self_check

- `all_numbers_have_source` — **критичен**. Это цифровая рубрика; любая цифра
  без записи в `facts` со ссылкой делает пост браком.
- `no_verbatim_copy` — **критичен**. Источники — новости и отчёты, велик соблазн
  скопировать формулировку. Переписывай своими словами.
- `no_guaranteed_returns` — критичен. Запрещены выводы «значит, цены будут
  расти» и «самое время покупать».
- `fits_telegram_limit` — проверить по `{{max_chars}}`.

## Чего не делать

- Не строить тренд по одной точке данных.
- Не сравнивать периоды, если во входных данных нет обоих значений.
- Не давать список из 10 цифр без интерпретации.
- Не писать «рекордный», «взрывной», «бьёт рекорды».
- Ноль эмодзи в этой рубрике.

## Формат ответа — строго валидный JSON

Верни ТОЛЬКО JSON-объект по схеме ниже. Без markdown-обёртки, без тройных
кавычек, без комментариев, без текста до или после. Первый символ ответа — `{`,
последний — `}`.

```json
{
  "rubric": "<rubric_id>",
  "title": "строка, не длиннее 90 символов, без markdown",
  "body": "строка, текст поста; разрешены только теги <b>, <i>, <a href=\"...\"> (Telegram HTML)",
  "hashtags": ["#дубай", "#недвижимость"],
  "cta": "строка, одна фраза призыва к действию",
  "image": {
    "mode": "card",
    "headline": "строка не длиннее 60 символов для фирменной карточки",
    "accent": "строка не длиннее 18 символов: цифра-акцент, либо пустая строка",
    "stock_query": "english keywords for Unsplash/Pexels fallback"
  },
  "sources": [{"source_id": "...", "title": "...", "url": "https://..."}],
  "facts": [{"claim": "...", "value": "...", "source_url": "https://..."}],
  "self_check": {
    "all_numbers_have_source": true,
    "no_guaranteed_returns": true,
    "language_is_russian": true,
    "no_verbatim_copy": true,
    "fits_telegram_limit": true
  },
  "length_chars": 0,
  "needs_separate_text": false
}
```

Обязательные условия по полям:
- `rubric` — ровно то значение, что пришло в `RUBRIC_ID` выше (`{{rubric}}`).
- `title` — до 90 символов, без markdown и без эмодзи.
- `body` — только теги `<b>`, `<i>`, `<a href="...">`; переносы строк как `\n`.
- `hashtags` — 2–4 штуки, строчными, по-русски, первым `#дубай`.
- `cta` — одна фраза; она же дублируется в конце `body`.
- `image.mode` — `"card"`, `"stock"` или `"press"` согласно разделу «Изображение».
- `image.headline` — до 60 символов; `image.accent` — до 18 символов или `""`.
- `image.stock_query` — на английском, 3–6 слов, заполняется всегда.
- `sources[].source_id` — идентификатор источника **ровно так, как он пришёл
  в поле `source_id` соответствующего элемента `<INPUT_ITEMS>`** (например
  `gulf_news_rss`, `dld_open_data_portal`). Не подставляй сюда название
  категории и не придумывай новых идентификаторов.
- `sources[].url` — только из `<INPUT_ITEMS>`; конструировать ссылки запрещено.
- `facts` — по одной записи на каждую цифру, встречающуюся в `body`.
- `self_check` — честная самопроверка; `false` лучше, чем ложный `true`.
- `length_chars` — фактическая длина `body` в символах.
- `needs_separate_text` — `true`, если полный текст не помещается в
  `{{max_chars}}` и нужна вторая часть отдельным сообщением.
