# Рубрика: meme — «Мем дня»

RUBRIC_ID: {{rubric}}
TODAY: {{today}}
MAX_CHARS: {{max_chars}}

## Входные данные

Свежие новости недели. Мем должен быть **про одну из них** — иначе он не
«актуальный», а просто шутка про Дубай:

<INPUT_ITEMS>{{items}}</INPUT_ITEMS>

## Цель поста

Разрядить ленту. Канал в основном про новости, правила и проекты — мем даёт
читателю улыбнуться и узнать себя. Это единственная рубрика, где шутка
разрешена и обязательна. Остальные правила голоса действуют: просто, без
капса, без «!!!», к читателю на «вы».

Хороший мем здесь — про **быт покупателя, арендатора и жителя города**,
привязанный к новости по теме канала (недвижимость, стройка и архитектура,
правила): аренда и переезд, брокеры и «последний юнит», рассрочка «до ключей»,
сдача «в конце 2029», новая башня рядом с окнами, пробки и новая дорога,
Salik, RTA, DEWA, метро, парковки, штрафы и новые правила, визы.
Читатель должен подумать: «это про меня». Темы вне канала (еда, красота,
знаменитости, спорт, концерты) для мема не годятся — `skip`.

## Три формата — выбери один

Картинку рисует код по полю `image.meme`. Текст в `lines` попадёт на
картинку **дословно**, поэтому он короткий и без эмодзи.

1. **`nobody`** — «Никто: / Абсолютно никто: / Дубай: …».
   `lines`: одна строка — что «сделал» Дубай. До 90 символов.
   Пример: `["+1 дорога к Марине. Пробка тоже +1"]`.
2. **`expectation`** — «Ожидание / Реальность».
   `lines`: две строки, ожидание и реальность, каждая до 70 символов.
   Пример: `["Сдача в 4 квартале 2027", "Ключи, когда ребёнок пойдёт в школу"]`.
3. **`me_vs`** — «Я: / Тоже я:».
   `lines`: две строки до 70 символов.
   Пример: `["Смотрю квартиры только до 1,5 млн", "Открываю объявление за 2,4 — ну посмотреть же можно"]`.

Есть ещё `one_liner`: `lines` = [короткая подводка, панчлайн]. Используй,
если ни один из трёх не ложится.

## Текст поста (`body`)

Коротко, 120–300 символов:
1. Одна строка — о какой новости речь, простыми словами (чтобы понял и тот,
   кто новость не видел). Без ссылок и без названий каналов.
2. Сам мем текстом (те же строки, что на картинке, в формате «Никто: /
   Абсолютно никто: / Дубай: …» и т.п.) — для тех, у кого картинки не
   грузятся.
3. По желанию одна строка от себя: «узнали себя?», «у меня так каждый
   сентябрь».
4. Хештеги, первым `#дубай`, дальше `#мем`.

`title` — новость одной простой фразой, без шутки (она пойдёт в очередь и в
статистику). `cta` — пустая строка или «Напишите, если у вас так же».

## Правила юмора (нарушение = брак)

Можно: добрая самоирония жителя, покупателя, брокера (в том числе про себя —
«я»), про цены, ожидание ключей, стройку за окном, пробки, парковки, правила.

**Нельзя ни в каком виде:**
- шутить о национальностях, религии, языке, акценте, внешности, полу, возрасте;
- о правителях, правительстве, полиции, судах, законах и штрафах как о
  чём-то смешном или несправедливом; о политике любой страны, войне;
- о смертях, авариях, болезнях, преступлениях, пострадавших, катастрофах —
  такие новости для мема **не подходят**, верни `skip`;
- о конкретных людях, компаниях, застройщиках и проектах в насмешливом или
  негативном ключе (имя застройщика в мем не попадает вообще);
- о клиентах, их деньгах и решениях;
- сарказм в адрес читателя, злая ирония, чёрный юмор, мат, пошлость;
- «цены рухнут», «пузырь», «все разорятся» и любые прогнозы рынка в шутке;
- эмодзи в `lines` и `title`; в `body` — максимум один.

Если ни одна новость из входных данных не подходит под добрый бытовой мем —
верни `{"skip": true, "skip_reason": "..."}`. Натянутый мем хуже, чем никакого.

## Цифры

В меме цифр лучше избегать. Если цифра всё же нужна (год сдачи, число
полос), она берётся **только** из входных данных и дублируется в `facts`.
Придуманная цифра — брак.

## Изображение

- `image.mode`: `"meme"`
- `image.meme.format`: `nobody` | `expectation` | `me_vs` | `one_liner`
- `image.meme.lines`: строки по формату выше, без эмодзи и без кавычек-ёлочек
  в начале.
- `image.headline`: та же новость одной фразой до 60 символов (запасной
  вариант, если мем не отрисуется).
- `image.accent`: `""`.
- `image.stock_query`: по теме на английском (не используется, но поле обязательно).

## Критичные self_check

- `all_numbers_have_source` — если цифр нет, ставь `true`.
- `no_verbatim_copy` — новость пересказана, не скопирована.
- `language_is_russian`, `fits_telegram_limit`.

## Формат ответа — строго валидный JSON

Верни ТОЛЬКО JSON-объект по схеме ниже. Без markdown-обёртки, без тройных
кавычек, без комментариев, без текста до или после. Первый символ ответа — `{`,
последний — `}`.

```json
{
  "rubric": "<rubric_id>",
  "title": "строка, не длиннее 90 символов, без markdown",
  "body": "строка, текст поста; разрешены только теги <b>, <i>, <a href=\"...\"> (Telegram HTML)",
  "hashtags": ["#дубай", "#мем"],
  "cta": "строка или пустая строка",
  "image": {
    "mode": "meme",
    "meme": {
      "format": "nobody | expectation | me_vs | one_liner",
      "lines": ["строка 1", "строка 2 (если формат двухстрочный)"]
    },
    "headline": "строка не длиннее 60 символов — новость одной фразой",
    "accent": "",
    "stock_query": "english keywords"
  },
  "sources": [{"source_id": "...", "title": "...", "url": "https://..."}],
  "facts": [
    {
      "claim": "...",
      "value": "...",
      "source_url": "https://...",
      "confidence": "confirmed | single_source | rumour",
      "sources": ["https://...", "https://..."]
    }
  ],
  "self_check": {
    "all_numbers_have_source": true,
    "no_guaranteed_returns": true,
    "language_is_russian": true,
    "no_verbatim_copy": true,
    "fits_telegram_limit": true
  },
  "length_chars": 0,
  "needs_separate_text": false
}
```

Обязательные условия по полям:
- `rubric` — ровно то значение, что пришло в `RUBRIC_ID` выше (`{{rubric}}`).
- `title` — до 90 символов, без markdown и без эмодзи.
- `body` — только теги `<b>`, `<i>`, `<a href="...">`; переносы строк как `\n`.
- `hashtags` — 2–4 штуки, строчными, по-русски, первым `#дубай`, вторым `#мем`.
- `image.meme.lines` — 1 строка для `nobody`, 2 для остальных форматов.
- `sources[].source_id` — идентификатор источника **ровно так, как он пришёл
  в поле `source_id` соответствующего элемента `<INPUT_ITEMS>`**; хотя бы один
  источник — новость, про которую мем.
- `sources[].url` — только из `<INPUT_ITEMS>`; конструировать ссылки запрещено.
- `facts` — по одной записи на каждую цифру в `body` и в `lines`; при
  отсутствии цифр — пустой список.
- `self_check` — честная самопроверка; `false` лучше, чем ложный `true`.
- `length_chars` — фактическая длина `body` в символах.
- `needs_separate_text` — всегда `false`: мем короткий.
