# Рубрика: rules_and_laws — «Правила игры»

RUBRIC_ID: {{rubric}}
TODAY: {{today}}
MAX_CHARS: {{max_chars}}

## Входные данные

Единственный разрешённый источник фактов, порогов и сроков:

<INPUT_ITEMS>{{items}}</INPUT_ITEMS>

Приоритет источников: категория `city_gov` (официальные порталы ОАЭ и эмирата)
и `official_data`. Пересказ блогов и статей агентств источником не является —
если во входных данных только они, снижай категоричность формулировок и прямо
пиши, что правило надо сверить на официальном портале.

## Цель поста

Объяснить одно правило, изменение или проверку так, чтобы читатель понял,
касается ли это его и что делать. Рубрика для резидентов и экспатов: визы,
штрафы, налоги и сборы, трудовые правила, аренда, проверки, новые законы.

Подходит:
- новое правило, закон, тариф, штраф, порог — что изменилось и с какого числа;
- процедура с шагами (виза, регистрация, оформление) — если она есть в данных;
- новости о проверках и нарушениях (например, выявленные фиктивные схемы) —
  подача «что проверяют и как не попасть».

Если во входных данных есть только факт изменения без пошаговой процедуры —
пиши формат «что изменилось → кого касается → что делать», а не пропускай.

## Структура

1. **Заголовок** — конкретное правило или изменение простой фразой.
2. **Что изменилось / что проверяют** — 1–2 предложения.
3. **Кого касается** — одна строка.
4. **Что делать** — 2–4 шага или пункта через тире (если данных на шаги нет —
   один совет: где проверить, к какому сроку).
5. **Где проверить** — первоисточник живым текстом; если источник —
   Telegram-канал или СМИ, так и написать: «просто фактом, без ссылок на каналы».
6. **Хештеги.**

## Длина

Целевая: 600–900 символов. Потолок: `{{max_chars}}`.
Если процедура длинная — оставь шаги, вынеси подводные камни во второе
сообщение, `needs_separate_text: true`.

## CTA

Мягкий:

- «Есть вопрос по вашей ситуации — задайте в боте, разберу в рубрике
  „Вопрос — ответ“.»
- «Сохраните пост — правила меняются, но порядок шагов обычно остаётся.»

## Изображение

- `image.mode`: `"card"`
- `image.headline`: название правила, до 60 символов, без эмодзи.
- `image.accent`: ключевой порог, срок или процент, до 18 символов, только если
  эта цифра есть в `facts`. Иначе `""`.
- `image.stock_query`: `"dubai government documents passport visa desk"`.

## Критичные self_check

- `all_numbers_have_source` — критичен. Пороги, пошлины, сроки, проценты —
  только из входных данных.
- `no_guaranteed_returns` — в этой рубрике читается шире: **нельзя обещать
  результат процедуры**. Не «визу дадут», а «заявка подаётся так-то, решение
  принимает орган».
- `no_verbatim_copy` — критичен: официальные тексты копируются буквально
  особенно часто.
- `fits_telegram_limit`.

## Чего не делать

- Не давать налоговых и юридических консультаций по стране резидентства
  читателя. Только правила ОАЭ.
- Не писать правило без даты актуальности.
- Не утверждать категорично, если источник — не официальный портал.
- Не обещать сроки рассмотрения, если их нет в источнике.
- Ноль эмодзи в этой рубрике.

## Формат ответа — строго валидный JSON

Верни ТОЛЬКО JSON-объект по схеме ниже. Без markdown-обёртки, без тройных
кавычек, без комментариев, без текста до или после. Первый символ ответа — `{`,
последний — `}`.

```json
{
  "rubric": "<rubric_id>",
  "title": "строка, не длиннее 90 символов, без markdown",
  "body": "строка, текст поста; разрешены только теги <b>, <i>, <a href=\"...\"> (Telegram HTML)",
  "hashtags": ["#дубай", "#недвижимость"],
  "cta": "строка, одна фраза призыва к действию",
  "image": {
    "mode": "card",
    "headline": "строка не длиннее 60 символов для фирменной карточки",
    "accent": "строка не длиннее 18 символов: цифра-акцент, либо пустая строка",
    "stock_query": "english keywords for Unsplash/Pexels fallback"
  },
  "sources": [{"source_id": "...", "title": "...", "url": "https://..."}],
  "facts": [
    {
      "claim": "...",
      "value": "...",
      "source_url": "https://...",
      "confidence": "confirmed | single_source | rumour",
      "sources": ["https://...", "https://..."]
    }
  ],
  "self_check": {
    "all_numbers_have_source": true,
    "no_guaranteed_returns": true,
    "language_is_russian": true,
    "no_verbatim_copy": true,
    "fits_telegram_limit": true
  },
  "length_chars": 0,
  "needs_separate_text": false
}
```

Обязательные условия по полям:
- `rubric` — ровно то значение, что пришло в `RUBRIC_ID` выше (`{{rubric}}`).
- `title` — до 90 символов, без markdown и без эмодзи.
- `body` — только теги `<b>`, `<i>`, `<a href="...">`; переносы строк как `\n`.
- `hashtags` — 2–4 штуки, строчными, по-русски, первым `#дубай`.
- `cta` — одна фраза; она же дублируется в конце `body`.
- `image.mode` — `"card"`, `"stock"` или `"press"` согласно разделу «Изображение».
- `image.headline` — до 60 символов; `image.accent` — до 18 символов или `""`.
- `image.stock_query` — на английском, 3–6 слов, заполняется всегда.
- `sources[].source_id` — идентификатор источника **ровно так, как он пришёл
  в поле `source_id` соответствующего элемента `<INPUT_ITEMS>`** (например
  `gulf_news_rss`, `dld_open_data_portal`). Не подставляй сюда название
  категории и не придумывай новых идентификаторов.
- `sources[].url` — только из `<INPUT_ITEMS>`; конструировать ссылки запрещено.
- `facts` — по одной записи на каждую цифру, встречающуюся в `body`;
  `confidence` — `confirmed`, `single_source` или `rumour` по правилам раздела
  «Проверка и маркировка» системного промпта; `sources` — все url из
  `<INPUT_ITEMS>`, где этот факт встречается (первый дублируется в `source_url`).
- `self_check` — честная самопроверка; `false` лучше, чем ложный `true`.
- `length_chars` — фактическая длина `body` в символах.
- `needs_separate_text` — `true`, если полный текст не помещается в
  `{{max_chars}}` и нужна вторая часть отдельным сообщением.
