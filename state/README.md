# state/ — состояние пайплайна

GitHub Actions не хранит состояние между запусками, поэтому состоянием служит
сам репозиторий: каждый workflow читает и пишет JSON-файлы в этой папке, а
последним шагом коммитит изменения.

| Файл | Что хранит |
|---|---|
| `seen_items.json` | хэши уже виденных материалов — защита от повторов (дедупликация) |
| `queue.json` | очередь постов: черновики, слоты, статусы апрува |
| `published.json` | ключи идемпотентности и журнал публикаций |
| `telegram_offset.json` | offset `getUpdates` — чтобы не обрабатывать одни и те же нажатия дважды |
| `analytics.json` | по каждому посту: метаданные и метрики |
| `rubric_weights.json` | веса рубрик, пересчитанные по результатам недели |
| `sources_health.json` | результат последней проверки источников |
| `leads.json` | обезличенные заявки на лончи (**без контактов**) |

Реальные файлы `*.json` в `.gitignore` до первого запуска не нужны — они
создаются автоматически. В репозитории лежат только образцы `*.example.json`,
чтобы была видна структура.

**Никогда не кладите сюда персональные данные** — имена, телефоны, @username,
email. Подробности в `docs/SECURITY.md`.
